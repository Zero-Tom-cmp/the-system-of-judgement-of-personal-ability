# 人岗匹配评估系统

基于 **AHP-模糊综合评价** 的高校学生能力评估与岗位匹配系统。从学生的在校数据出发，自动测算各能力维度得分，与岗位能力模型比对得出匹配度，并输出可直接使用的简历。

> 完整设计说明见 [`docs/系统架构分析.md`](docs/系统架构分析.md)｜代码导读见 [`docs/代码阅读指南.md`](docs/代码阅读指南.md)

---

## 功能概览

系统按职责划分为 8 个模块：

| 模块 | 代号 | 职责 |
|---|---|---|
| 认证权限中心 | AUTH | 登录、JWT 签发校验、双层角色鉴权、越权拦截 |
| 数据导入中心 | IMPORT | Excel 一体化导入 / CSV 分模块导入、查重、冲突检测与下载 |
| 学生数据中心 | DATA | 学生 5 类数据的存储与增删改查：基本信息、课程、竞赛、实习、项目 |
| 培养方案中心 | PLAN | 能力维度定义、课程→能力映射、专业权重、毕业要求矩阵 |
| 能力评估中心 | EVAL | 5 类数据源加权贡献 → 归一化 → 0–100 能力分，含得分溯源 |
| 岗位匹配中心 | MATCH | 能力分与岗位要求比对，输出匹配度、维度差距与提升建议 |
| 简历输出中心 | RESUME | 数据提炼、技能关键词提取、模板渲染、PDF 导出 |
| 系统支撑中心 | SYS | 规则在线配置、数据总览看板、操作日志、数据库初始化与种子数据 |

**角色**：`admin`（教务/就业中心，全局数据 + 配置 + 审计） 与 `student`（仅本人数据）。

## 快速开始

### 方式一：一键启动（Windows）

双击 **`启动.bat`** —— 自动拉起后端与前端，并在就绪后打开浏览器。
停止服务双击 **`停止.bat`**。

> ⚠️ `启动.bat` 里的 Python 与 Node 路径是按开发机写死的（`PY` 变量）。
> 换机器需要在脚本开头改这两个路径。

### 方式二：手动启动

```bash
# 后端（必须在 backend 目录下启动 —— 数据库用的是相对路径）
cd backend
pip install -r requirements.txt
python main.py                 # http://127.0.0.1:8000

# 前端
cd frontend
npm install
npm run dev                    # http://localhost:3000
```

前端开发服务器通过 Vite 代理把 `/api` 转发到 `http://127.0.0.1:8000`。

### 方式三：Docker

```bash
docker compose up
```

## 核心算法

### 能力评估

5 类数据源各自产生贡献分，汇总后归一化为百分制：

| 数据源 | 贡献上限 | 要点 |
|---|---|---|
| 课程 | ~40 | `(成绩/100) × 映射权重 × 学分占比 × 40`，受学分摊薄 |
| 竞赛 | ~15 | 级别分 × 奖项分 × 映射权重 |
| 企业实习 | ~10 | 按企业层次加权 |
| 项目经历 | ~10 | 按队内排名系数加权 |
| 英语证书 | 15 | 按 CET4/6、雅思、托福档位换算，不受学分摊薄 |

归一化：`s = min(1, raw / 40)`。**能力分只表达该维度有多强，不乘权重** —— 权重统一交给匹配公式，一个概念只出现一次。

### 岗位匹配

参考《基于AHP-模糊综合评价的人才岗位匹配度测算》，并修正了论文正文的两处公式笔误：

| 步骤 | 公式 |
|---|---|
| 单维度匹配度 | `mᵢ = 1 − \|sᵢ − rᵢ\|` |
| 综合匹配度 | `D = Σ eᵢ · mᵢ` |
| 百分制得分 | `Score = 100 · D` |
| 硬性门槛（扩展，默认关闭） | `D_final = D · Π gⱼ` |

其中 `sᵢ` 为学生能力分、`rᵢ` 为岗位要求值、`eᵢ` 为归一化权重。

> **本模型衡量的是「匹配」而非「优秀」** —— 能力超出岗位要求同样算偏离、同样扣分，界面上以橙色提示。

提升建议**仅在学生低于岗位要求时**生成，避免出现「已超出仍建议加强」的反向建议。

## 目录结构

```
├── backend/
│   ├── main.py            # FastAPI 入口，约 45 个 API 端点 + 鉴权
│   ├── database.py        # 建表、字段迁移、种子数据
│   ├── evaluation.py      # 能力评估引擎
│   ├── match_score.py     # 岗位匹配算法（纯函数，可单测）
│   ├── ability_score.py   # 能力分归一化
│   ├── resume.py          # 简历数据提炼、模板渲染、PDF 生成
│   ├── ahp.py             # AHP 层次分析法实现（备用，当前未接入主流程）
│   └── tests/             # 单元测试与接口测试
├── frontend/src/
│   ├── App.jsx            # 路由与角色守卫
│   ├── api.js             # axios 封装、Bearer 注入、401 处理
│   ├── components/        # 公共组件：雷达图、得分溯源、岗位匹配面板等
│   └── pages/             # admin/ 与 student/ 两套页面
├── docs/                  # 架构分析、功能架构图、代码阅读指南
├── resume-templates/      # 简历 HTML 模板
├── 启动.bat / 停止.bat     # Windows 一键启停
└── docker-compose.yml
```
