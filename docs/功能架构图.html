三、角色与权限设计（双层权限）

管理员 role = admin ｜ 教务 / 就业中心
数据总览 学生管理 学生检索 批量导入 模板下载 冲突下载 规则配置 批量删除 批量重置密码 操作日志 任意学生详情 能力评估 / 岗位匹配 / 简历
普通用户（学生） role = student ｜ 仅限本人数据
个人总览 课程成绩 竞赛获奖 企业实习 项目经历 培养方案 实践能力评估 岗位匹配 简历 / PDF 修改本人密码 他人数据 数据增删改 导入 / 配置 操作日志
权限落地三道闸：① 前端路由守卫（分流 /admin 与 /student）→ ② 后端接口鉴权（真正的安全边界，比对 URL 中的 student_id）→ ③ 数据层约束（外键级联删除）
